# 学业来源任务：课表、考试与成绩

目标模块：4.1。当前结论：三个能力均为 `BLOCKED_SOURCE_EVIDENCE`。本文件只记录来源问题和开工边界，不实现生产适配。

## 为什么不能直接用现有教务日历

现有 `learn.calendar` 通过 Learn SSO 读取选定区间的教务教学日历，字段为 `nq`、`kssj`、`jssj`、`nr`、`dd`、`fl`。代码自己的范围说明是：

> Selected registrar teaching calendar via Learn SSO; not all teaching or exam arrangements

因此它：

- 不是完整的个人课表；
- 不覆盖全部考试安排；
- 不提供可靠的学期/课程/周次/教室稳定映射；
- 不能把 `fl` 当作事件确认状态；
- 不能因为某天没有返回行就推断“没有课”或“没有考试”。

## 三项独立任务

| 任务 | 需要回答 | 已知 | 缺失 | 禁止推断 |
|---|---|---|---|---|
| `task.academics.timetable` | 个人课表的官方来源、学期、课程、周次、教室、occurrence 是什么 | 只有教学日历；无课表解析器 | 端点和页面、课程/学期标识、周次规则、教室、完整范围 | 不从教学日历推导完整课表；不按标题或数组位置识别课程 |
| `task.academics.exams` | 考试场次、日期、时间、教室、座位、发布/取消状态是什么 | 代码明确说日历不覆盖全部考试 | 考试来源、场次标识、时间精度、座位、发布状态 | 不从教学日历推导考试；不把缺失当没有考试 |
| `task.academics.grades` | 课程成绩的来源、学期/课程关联、成绩制式、学分、发布状态是什么 | 只有作业成绩字段，属于 `assignment-v1` 不是课程成绩 | 成绩来源、课程/学期稳定关联、成绩制式、扣留/未发布语义 | 不把缺失成绩变 0；不计算 GPA/排名；不把作业成绩当课程成绩 |

机器可读任务：[source-tasks.json](../../contracts/v0.2/sources/source-tasks.json)。

## 允许现在做的工作

4.1 可以在不猜接口的前提下完成：

- `course-v1`、`grade-v1`、`calendar-event-v1` 的读取模型和失败路径；
- 合成账号、合成课程、合成考试、合成成绩夹具；
- `UNKNOWN`、`EMPTY`、`PARTIAL`、`AUTH_REQUIRED` 等状态；
- 同名课程、不同学期、缺稳定编号的拒绝合并测试；
- 未取得来源时的 `BLOCKED` 结果和官方页面提示。

不得完成：

- 声称生产课表/考试/成绩已可用；
- 用教学日历充当课表或考试表；
- 用占位接口、假响应或关闭测试让模块“通过”；
- 为制造证据而导出真实成绩单或提交真实业务。

## 解除阻塞所需的证据

由获得授权的本机维护者完成，仓库只保存脱敏结果：

1. 官方入口和访问前提（公开/登录/二次验证/权限）。
2. 字段清单：学期、课程、考试、成绩、时间精度、分页、总数和错误形状。
3. 稳定标识：来源记录号、课程号、学期号、考试场次号；哪些字段缺失。
4. 范围证明：是否完整、是否只覆盖当前学期、是否有隐藏页。
5. 一个合成样例和摘要哈希；不提交原始 HTML、Cookie、请求头、账号或成绩单。

取得证据后，更新 `source-registry.json` 的对应来源行和 `adapter-readiness.json` 的结论，再进入 4.1 生产适配。证据不足时，4.1 保持“模型和失败路径完成、生产读取阻塞”，不能把模块记成完整业务能力。
