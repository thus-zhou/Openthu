# 公开证据与隐私规则

本规则适用于 `contracts/v0.2/sources/`、`tests/fixtures/sources/` 和 `docs/contracts/`。目标是让公开仓库能复现字段和失败语义，同时不携带任何个人数据。

## 可以提交

- 官方入口 URL（去掉 ticket、token、cookie、签名和会话参数）。
- 字段名、字段位置、类型、分页参数、总数/下一页字段。
- 状态映射、错误类别和不可推断规则。
- 合成账号、合成课程、合成作业、合成订单、合成图片的元数据。
- 摘要哈希（对规范化合成样例或公开说明计算）。
- 代码位置（相对路径和行号）。
- 未决问题、阻塞原因和下一步。

## 不得提交

- 真实姓名、学号、账号、邮箱、手机号、宿舍、成绩单、课表、借阅记录、预约记录、订单、付款信息。
- Cookie、请求头、Authorization、ticket、CSRF、session、签名、密钥、密码、验证码。
- 原始 HTML、原始 JSON 响应、截图、日志、主机名、绝对用户目录。
- 任何可用于重放真实业务的请求体。
- 真实图片或附件内容。

## 证据记录格式

来源行至少包含：`source_id`、服务、操作、证据类别、版本、检查时间、字段映射、分页规则、未决问题、写入副作用和 `raw_payload_included=false`。规范模型样例必须带 `synthetic=true`。

## 检查

```sh
python contracts/v0.2/sources/validate.py
python scripts/dev.py check
```

来源校验器会：

1. 用 JSON Schema 2020-12 校验来源登记和 10 个规范模型；
2. 断言每个兼容样例通过、每个拒绝样例被拒绝；
3. 检查每个计划能力都有负责人、启动结论和可追溯来源；
4. 检查公开文件中没有绝对用户目录、私钥、密码或认证字段；
5. 检查合成夹具覆盖登录页 200、同名课程、缺失稳定编号、空/下一页/失败、上传/草稿/提交、续借失败和模型目录不一致。

## 版本与回退

1. 证据结论变化时新增版本记录和原因，不覆盖旧结论。
2. 旧契约仍可按原版本解析；新字段默认可选。
3. 某来源撤回或改版时，禁用受影响适配，其他独立服务继续使用此前已验证契约。
4. 回退代码不撤销已经发生的远端业务；未决事务保留原密钥、原记录和核对路径。
5. 缺少可靠来源时保持 `BLOCKED`，不用占位接口、真实个人数据或关闭测试消除问题。
