# 后续开发计划

按独立 Issue 推进，不把计划文字当成已实现功能。

1. 改善初次安装、依赖诊断、跨平台离线测试和错误帮助；维护首个公开版本的可复现构建。
2. 在本机复核当前校园入口、登录与主要只读流程，公开无个人信息的结果；更新能力矩阵。
3. 对图书馆和体育现有办理补齐具体事项下的真实验收。没有业务需求时继续标记写入待验证。
4. 亲友来访：先核对当前官方入口、字段、申请记录及审批语义，再设计专用只读/办理适配；公众参观保持独立能力。附件上传、草稿和撤回分别核对授权及结果。
5. 设计 Linux 的生产级凭据存储与认证方案；不得用明文落盘绕过 Windows 依赖。
6. 课表考试、成绩培养方案、校内通知、云盘等另建独立需求，先确认资料来源和权限。

每项交付包含代码、必要测试、当前验证级别、已知限制、回滚方法和下一位负责者。
