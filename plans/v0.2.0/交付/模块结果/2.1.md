## 交付范围

- `src/thu_assistant/configuration.py`：命令行、`OPENTHU_*` 环境变量、本机 JSON 和默认值的四层配置；未知/重复键、非法类型、URL、秘密字段和资源根返回稳定错误码；`read_config()` 只读取 `OPENTHU_SECRET_<NAME>`，不把秘密放进配置对象或公开摘要。
- `src/thu_assistant/paths.py`：统一资源、状态、下载、临时和日志路径；资源清单区分文件和目录，源码与包安装共用逻辑 ID；拒绝仓库内状态、密钥目录、相对路径和不可写父目录；提供迁移预览。
- `scripts/dev_diagnostics.py`：`doctor` 覆盖 `development`、`readonly`、`browser`、`production-auth`、`packaging`、`config` 六类；状态为通过/警告/失败/不适用；公开报告只含逻辑检查项、脱敏版本、仓库相对资源名和修复命令。
- `scripts/dev.py`：新增 `doctor` 与 `--json`，`check` 先运行统一诊断；`setup-node`、`smoke`、`test` 保留原入口和退出语义；`runtime.python`、`runtime.node`、超时和输出上限实际生效。
- 新增 `configs/openthu.example.json`、`tests/test_configuration.py`、`tests/test_dev_diagnostics.py`，更新 README、INSTALL、CHANGELOG。

## 剩余边界

- 当前云主机为 Linux；Windows DPAPI/ACL 行为只能在 Windows CI 或 Windows 本机验证。
- `doctor` 只证明依赖和文件布局，不证明真实校园登录、权限或业务成功。
- 诊断的修复提示是公开命令模板，不读取用户目录或凭据。
- `learn_assistant` 和 `configure_mcp.py` 的旧路径/环境默认值属于后续模块，2.1 未越权修改。
