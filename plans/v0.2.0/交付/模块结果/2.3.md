## 剩余边界

- 这是离线证据包：没有真实校园登录、读取、预约、付款或提交，不能据此声称任何业务能力已上线。
- registry 记录的是现状字段和目标规范字段；3.2/4.1/4.5/5.1/5.3 仍需实现运行时规范化（空标题、角色大写、续借身份）。
- `library.renewal` 的资格读取是 `PARTIAL/LIMITED`，只有续借执行阻塞。
- `visitors.form` 只有公开入口，当前表单与权限契约仍阻塞 4.4。
- JSON Schema 不能表达全部业务语义；`validate.py` 的显式检查是可执行的那部分。
