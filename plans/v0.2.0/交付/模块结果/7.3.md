## 边界与限制

- 本模块是文档与文档测试，不改变运行时行为、能力状态或工具 schema；能力结论以代码和登记表为准，文档不提升证据等级。
- 本机只执行 Linux；Windows 的文档可读性与命令兼容由 CI 的 `windows-2025` job 覆盖，未在本机 Windows 主机复现。
- 真实校园认证、写入、付款、交作业、模型图片传输均未在本模块执行；文档只记录已有证据与阻塞。
- `local.resources` 在默认 CLI/MCP/看板中仍为 `RESOURCE_PROVIDER_UNAVAILABLE`；手册给出宿主 API 用法，不把它写成已接通的公共入口。
- 看板 HTML 外壳属于同批 7.1；本模块只描述 API、只读路由与 `LOCAL_API_UI_NOT_INSTALLED` 边界，不声称外壳已交付。
- `actions.py` 顶部仍有旧 docstring “No campus write adapter is enabled in block 5”；该文件归 4.4，本模块未修改，已在 `docs/contracts/source-matrix.md` 的差异表中保留为 4.4 事项。
- `docs/contracts/source-matrix.md` 属 2.3 负责的来源证据文档；本模块未修改其内容，其中“4.4/7.3 统一措辞”一行仍是历史登记，由 2.3/8.1 在回接时更新。
