## 关键安全属性

- 每次封装使用独立随机 12 字节 nonce；同一记录重复写入得到不同密文。
- AAD 绑定格式版本、用途、账号域、服务域、账号伪名和修订号；修改头、nonce、密文或域均失败关闭。
- 主密钥为随机 32 字节秘密，不由主机名/用户名派生；Linux 密钥文件必须在数据目录之外，Windows 密钥由当前用户 DPAPI 包装。
- 账号伪名由受保护的随机命名空间密钥经 HKDF 分离后 HMAC 生成；轮换数据密钥后保持稳定，跨账号/跨用途读取被拒绝。
- 旧 `LA-DPAPI-1`、`THU-ACTION-1`、`THU-TODOS-1` 仅在匹配的 Windows 用户下只读；跨平台读取返回需要重新建立会话。
- 轮换先逐条解封、重封、核验，再原子切换 `store.json`；失败保留旧指针、旧目录和旧密钥，不自动清理。
- 错误只包含稳定错误码，不含路径、账号、密钥或密文。

## 剩余边界

- 当前云主机为 Linux；Windows DPAPI/ACL 用例已在 GitHub `windows-2025` runner 通过，不在本机执行。
- 本批发现并修复了 Windows 特有缺陷：PowerShell 5.1 启动挂起（改用 PowerShell 7）、ACL 所有者和别名、`os.open` 缺少 `O_BINARY` 导致密文换行翻译、私有桥缺少 profile 变量。
- 不承诺抵抗能同时替换数据与指针的完整目录回滚；修订号只解决普通并发写入。
- 不提供跨机器密钥迁移、自动清理旧密文或安全内存擦除。
- `pyproject.toml` 的最终运行时依赖和锁由 6.3 负责；本模块只加入开发依赖，保证 CI 可运行。
