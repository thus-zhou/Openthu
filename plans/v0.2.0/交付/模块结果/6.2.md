## 交付范围

- `src/thu_assistant/local_api/contract.py`：冻结 `local-read-api-v1` 的路由、限制、状态与错误码运行时镜像。
  七个路由与契约逐项一致；方法只允许 `GET`/`HEAD`；绑定只允许 `127.0.0.1`/`::1`；
  Host 允许表、请求体 64 KiB、分页 50/200、等待 30 秒、刷新间隔 10 秒、游标 600 秒均从契约读取并集中配置。
  路由表扫描确认不存在 execute、prepare、payment、upload、cancel、renew、book、model、key、config、proxy 等入口。
- `local_api/facade.py`：消费侧 `BusinessFacade` 协议（`health`、`services`、`query`、`describe`、
  `todos`、`calendar`、`resources`），6.2 不导入 6.1 的私有实现；`UnavailableFacade` 在无校园账户、
  无门面时也能启动，并返回 `UNKNOWN` + `ADAPTER_REQUIRED` + `implementation_state=BLOCKED`，
  不会把缺能力伪装成空结果。`CancelToken` 支持协作取消。
- `local_api/security.py`：回环边界。`0.0.0.0`/`::`/外部地址在开 socket 前即拒绝；Host 精确允许
  `127.0.0.1`、`localhost`、`[::1]` 加实际端口，防 DNS 重绑定；Origin 与 `Sec-Fetch-Site` 拒绝跨站页面；
  不产生任何 `Access-Control-Allow-Origin`。会话与进程实例绑定：浏览器首屏走受信回环导航，
  自动化客户端走 0600 文件加 `X-Openthu-Bootstrap` 头；令牌不进 URL、启动日志或公共配置。
  Cookie 为 `HttpOnly; SameSite=Strict; Path=/`，无 `Domain`，有界 `Max-Age`；不设 `Secure`
  是因为部分浏览器在回环 HTTP 上会丢弃。会话只保存 SHA-256 摘要，空闲/绝对过期与未知 Cookie 分开。
  速率限制为每会话 120 次/10 秒，相同昂贵读取另有 10 秒最小间隔，游标续页不当作刷新。
- `local_api/server.py`：请求处理与生命周期。依次检查路径、Host、Origin、方法、请求体、静态资源、
  抓取元数据、路由、会话、速率、参数，再调用门面。门面调用带 30 秒默认截止时间与取消令牌；
  单源超时返回 504 `TIMEOUT`，其他卡片继续。`stop()` 只取消本实例持有的请求、关闭本实例 socket、
  关闭执行器并删除本实例的 bootstrap 文件，不发信号、不杀进程。每个实例独立 socket/执行器/文件；
  多实例关闭其中一个不影响另一个。入站日志只记录方法、路由名、状态、请求编号和耗时，
  不记录查询串、Cookie 或令牌。
- `local_api/projection.py`：展示投影。精确匹配的 cookie/token/session/authorization/member/
  student_id/path/file_path/pid/host/headers/exception/jwt 等键被丢弃；家庭目录、Windows 用户目录、
  临时目录、Bearer/JWT/API token 形态被替换为 `[REDACTED]`；文本截断、深度与列表上限有界，
  NaN/Infinity 变成 null。链接仅保留 `https://*.tsinghua.edu.cn` 且不含 CAS/SSO/login/ticket
  的地址，其余置 null 并加 `LOCAL_API_LINK_WITHHELD`。每个响应附加 `display.state`、
  `display.message`、`display.next_step`、`display.completeness`、`display.provenance`、
  `display.paging`；失败的来源仍是失败，`AUTH_REQUIRED` 是 200 的未登录卡片而不是空列表。
- `local_api/paging.py`：门面返回超过 `page_size` 的兜底切片。`lac1` 不透明游标绑定会话、路由、
  参数与页大小，600 秒过期；最后一页接回门面自带的 `next_cursor`，两种分页可以衔接。
  超过 5000 项或 16 MiB 返回 502 `LOCAL_API_RESPONSE_TOO_LARGE`，不静默截断成成功。
- `local_api/client.py`：本地自动化客户端。只连接回环来源，从 0600 文件读取 bootstrap 记录，

## 边界与保留限制

- 6.1 的真实业务门面尚未存在。当前生产默认是 `UnavailableFacade`：服务能启动、能显示能力缺口，
  但不返回业务数据。批次回接必须用 6.1 的适配器构造 `LocalApiServer`，协议见
  `src/thu_assistant/local_api/facade.py`。
- `local-read-api-v1` 在 `/todos`、`/calendar`、`/resources` 声明了 `next_cursor` 却没有声明请求侧
  `cursor`。本模块把 `cursor` 作为唯一、公开记录在 `describe_api()` 中的扩展；1.1/8.1 必须修订冻结
  契约或取消这三条路由的分页声明，其余参数与冻结清单完全一致。
- 静态界面只是接缝：6.2 只提供可选 `static_dir`，不拥有 HTML/CSS/JS；7.1 负责
  `src/thu_assistant/web_assets` 并把它传给服务器。没有静态目录时 `/` 返回
  `LOCAL_API_UI_NOT_INSTALLED`，JSON API 仍可用。
- 浏览器会话依赖受信回环导航（`Sec-Fetch-Site: none|same-origin`）；自动化客户端依赖 0600 文件
  与头部。同一 OS 账号的本地进程被视为可信（它本来就能读取用户资料），远程页面由 Host、Origin
  与抓取元数据拦截。Cookie 不设 `Secure`，回环 HTTP 是当前传输边界；将来若加 TLS 前端必须补上。
- 本版本不存在非读取路由，因此防伪令牌辅助函数只有单元用例，没有路由消费。未来任何刷新或写入
  路由必须同时校验来源与 CSRF 令牌后才能执行。
- 速率与刷新间隔是工程限制，不是学校规定；不同查询和游标续页不受 10 秒间隔影响。
- bootstrap 文件的属主/权限断言仅在 POSIX 生效；Windows 上文件仍位于按用户隔离的状态目录，
  会话仍绑定进程，但 0600 断言跳过。
- 展示投影不是通用 DLP：它丢弃已知敏感键并脱敏已知路径/令牌形态，但适配器仍必须保证
  envelope 内不出现原始凭据、成员原值和私人路径。
- 分页兜底对超过 5000 项或 16 MiB 的门面页返回 502，避免把截断结果写成成功；正确做法仍是
  门面在来源侧分页。
- 一次全量尝试命中 `tests/test_action_framework.py::test_concurrent_execute_dispatches_once`
  的 `STATE_READ_FAILED`。这是 4.4 的动作存储并发竞态，不涉及 6.2 代码；随后整轮全量通过。
  本记录保留该观察，交由 4.4/8.1 稳定化，而不是隐藏或改写。
- 所有验证均为合成门面与回环 HTTP；没有真实账户、来源、模型或浏览器，路由表中也没有预约、
  提交或付款入口。
