## 交付范围

- `local_api/contract.py`：冻结 `local-read-api-v1` 的路由、限制、状态与错误码运行时镜像。
  七个路由与契约逐项一致；方法只允许 `GET`/`HEAD`；绑定只允许 `127.0.0.1`/`::1`；
  Host 允许表、请求体 64 KiB、分页 50/200、等待 30 秒、刷新间隔 10 秒、游标 600 秒均集中配置。
  路由表扫描确认不存在 execute、prepare、payment、upload、cancel、renew、book、model、key、config、proxy 等入口。
  新增的 `check_envelope` 覆盖 `result-envelope-v1` 已声明的全部属性：类型、枚举、长度、
  `items` 数组、`snapshot_complete`、`missing_pages`、`source_errors`、错误对象形状与非有限数；
  任何不符返回 502，不再发出 schema 非法的 200/READY。
- `local_api/facade.py`：消费侧 `BusinessFacade` 协议（`health`、`services`、`query`、`describe`、
  `todos`、`calendar`、`resources`），6.2 不导入 6.1 的私有实现。协议明确要求适配器声明 `cancel`
  并在 `ui_wait_seconds` 内响应，同时要求 `source.service_id`/`operation` 与请求路由一致。
  `call_with_token` 用 `inspect.signature` 判断参数，不再因异常文本重试；门面缺少某个方法时
  返回 501 `LOCAL_API_FACADE_UNAVAILABLE`。`UnavailableFacade` 在没有校园账户、没有门面时仍能启动，
  返回 `UNKNOWN` + `ADAPTER_REQUIRED` + `implementation_state=BLOCKED`，不伪装成空结果。
- `local_api/security.py`：回环边界。`0.0.0.0`/`::`/外部地址在开 socket 前拒绝；Host 精确允许
  `127.0.0.1`、`localhost`、`[::1]` 加实际端口；Origin 与 `Sec-Fetch-Site` 在 API 和静态路由之前检查；
  不产生 `Access-Control-Allow-Origin`。会话与进程实例绑定：浏览器首屏走受信回环导航，
  自动化客户端走 0600 文件加 `X-Openthu-Bootstrap` 头。bootstrap 令牌一次性使用，兑换后文件立即删除；
  读取用 `O_NOFOLLOW` + `fstat` + 单描述符有界读取。Cookie 为 `HttpOnly; SameSite=Strict; Path=/`，
  无 `Domain`，有界 `Max-Age`；不设 `Secure` 是因为部分浏览器在回环 HTTP 上会丢弃。会话只保存
  SHA-256 摘要；同名 Cookie 的多个候选值都会验证；会话满额返回 `LOCAL_API_SESSION_LIMIT`，不驱逐活跃会话。
- `local_api/server.py`：请求处理与生命周期。依次检查路径、Host、Origin、方法、请求体、抓取元数据、
  静态资源、路由、会话、速率、参数，再调用门面。健康、服务目录和详情使用 2 线程优先级执行器；
  昂贵读取使用 8 线程执行器且容量由工作线程持有，8 个不响应取消的适配器也不会阻塞 `/health`，
  第 9 个读取快速返回 503 `LOCAL_API_BUSY`。门面调用带 30 秒默认截止时间与取消令牌；
  单源超时返回 504 `TIMEOUT`。刷新间隔只在非 5xx 响应后记账，HEAD 与游标续页不消耗；
  本地 429 使用 `LOCAL_API_RATE_LIMITED` 和本地文案。`stop()` 只取消本实例请求、关闭本实例 socket/
  执行器并删除本实例 bootstrap 文件，不发信号、不杀进程；多实例互不影响。日志只记录方法、路由名、
  状态、请求编号和耗时，不记录查询串、Cookie 或令牌。
- `local_api/projection.py`：展示投影。精确敏感键之外，按词段丢弃 `auth`、`cookie_header`、
  `csrf_token_value`、`*_header`、`*_api_key` 等凭据形态；家庭目录、Windows 用户目录、临时目录、
  Bearer/JWT/API token 形态被替换为 `[REDACTED]`；文本、深度与列表有界，非有限数变 null。
  链接对字符串、数组、映射三种形态都过滤：仅保留 `https://*.tsinghua.edu.cn` 且不含
  CAS/SSO/login/ticket 的地址，数组中不合法项变 null 并保留长度，告警带
  `LOCAL_API_LINK_WITHHELD_AT:<path>`。每个响应附加 `display.state`、`display.message`、
  `display.next_step`、`display.completeness`、`display.provenance`、`display.paging`；
  编码后超过 8 MiB 返回 502 `LOCAL_API_RESPONSE_TOO_LARGE`。
- `local_api/paging.py`：门面返回超过 `page_size` 的兜底切片。`lac1` 不透明游标绑定会话、路由、
  参数与页大小，600 秒过期；最后一页接回门面自带的 `next_cursor`。存储与游标表使用锁并原地删除；
  超过 8 MiB 返回 502，不静默截断成成功。
- `local_api/client.py`：本地自动化客户端。只连接回环来源，从 0600 文件读取 bootstrap 记录，
  第一次请求用头部换 Cookie，之后只带 Cookie；不把令牌放进 URL。
- `local_api/samples.py`：7.1 的固定合成样例与 `describe_api()` 接口说明（路由、限制、绑定、
  展示状态、错误码、样例、注意事项），全部为 `SYNTHETIC-*` 数据，不含真实账户或路径。

  非协作适配器、停止取消、多实例、投影与链接、错误分类、静态资源、日志隐私、无外部网络导入、

## 边界与保留限制

- 6.1 的真实业务门面适配器仍是批次回接步骤。6.2 现在要求七个方法齐全、
  `source.service_id`/`operation` 与请求路由一致、声明 `cancel` 且有界 I/O；缺少方法返回
  501 能力缺口，不伪造结果。
- `local-read-api-v1` 在 `/todos`、`/calendar`、`/resources` 声明了 `next_cursor` 却没有声明请求侧
  `cursor`。本模块把 `cursor` 作为唯一、公开记录在 `describe_api()` 中的扩展；1.1/8.1 必须修订冻结
  契约或取消这三条路由的分页声明，其余参数与冻结清单完全一致。
- 静态界面只是接缝：6.2 只提供可选 `static_dir`，不拥有 HTML/CSS/JS；7.1 负责
  `src/thu_assistant/web_assets` 并把它传给服务器。没有静态目录时 `/` 返回
  `LOCAL_API_UI_NOT_INSTALLED`，JSON API 仍可用。
- bootstrap 令牌一次性且兑换后删除文件；若本地会话过期，需要重启本地实例取得新令牌
  （浏览器导航路径不受影响）。这是移除可重放 300 秒令牌的代价。
- 浏览器会话依赖受信回环导航（`Sec-Fetch-Site: none|same-origin`）；同一 OS 账号的本地进程
  被视为可信（它本来就能读取用户资料），远程页面由 Host、Origin 与抓取元数据拦截。
  Cookie 不设 `Secure`，回环 HTTP 是当前传输边界；将来若加 TLS 前端必须补上。
- 本版本不存在非读取路由，因此防伪令牌辅助函数只有单元用例，没有路由消费。未来任何刷新或写入
  路由必须同时校验来源与 CSRF 令牌后才能执行。
- 速率与刷新间隔是工程限制：每会话 120 次/10 秒、相同昂贵读取 10 秒、8 个读取槽满时快速
  `LOCAL_API_BUSY`。HEAD 仍执行一次门面读取，但不占刷新配额，并受会话请求限流约束。
- 不响应取消的适配器线程无法在进程内终止。健康/目录仍可用、昂贵读取快速失败、`stop()` 有界返回，
  但 Python 在解释器退出时会 join 执行器线程，因此 6.1 必须给上游 HTTP 设置超时；
  永久阻塞的适配器仍可能拖慢进程退出。
- bootstrap 的属主/权限断言与 `O_NOFOLLOW` 仅在 POSIX 生效；Windows 使用显式符号链接检查，
  文件仍位于按用户隔离的状态目录，但 0600 断言跳过。
- 展示投影不是通用 DLP：它丢弃精确与凭据形态的键（`auth_state` 也被有意覆盖）并脱敏已知
  路径/令牌形态，但适配器仍必须保证 envelope 内不出现原始凭据、成员原值和私人路径。
- 响应上限为 8 MiB，分页存储共用；超过的门面页返回 502，避免把截断结果写成成功。
- 一次全量尝试曾命中 `tests/test_action_framework.py::test_concurrent_execute_dispatches_once`
  的 `STATE_READ_FAILED`。这是 4.4 的动作存储并发竞态，不涉及 6.2 代码；审计与最终两轮全量
  均未复现，记录保留给 4.4/8.1。
- 所有验证均为合成门面与回环 HTTP；没有真实账户、来源、模型或浏览器，路由表中也没有预约、
  提交或付款入口。
