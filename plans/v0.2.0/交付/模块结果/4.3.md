## 行为约定

1. **资源选择**：稳定编号优先；`name` 只接受唯一命中。同名区域、同名项目或同名场地返回
   `NEEDS_USER_ACTION` 和候选，不按数组顺序或标题相似度自动选择。
2. **余量与容量**：座位区域 `capacity` 来自 `seatinfo.TotalCount`，只表示区域总座位数；
   `free_count` 只统计目标时段。区域容量 300、该时段 0 个空位时输出
   `capacity=300, free_count=0, state=FULL`，`capacity_is_slot_availability=false`。
   体育顶层容量为 `null`，只有场次 `allowUserNum` 才是场次容量。研讨间人数范围是规则值，
   不是空闲容量。
3. **空闲不等于可准备**：研讨间 `availability.state=FREE` 与 `eligibility.state=INELIGIBLE`
   可以同时成立（人数不符、仅查看或账号受限），此时 `preparation_state=NOT_PREPARABLE`。
4. **实时读取**：新查询 `retrieval.freshness=LIVE_AT_CHECKED_AT`；游标续页
   `SNAPSHOT_ONLY_NOT_LIVE`、`current_source_read=false`、`reused_snapshot=true`，原
   `checked_at` 不变。余量没有缓存回退。
5. **分页**：座位历史固定 20 条/页；研讨间默认 `needStatus=6`；体育订单每页最大 50。
   这些窗口写入 `pagination`。重复页、缺页或总数变化时保留已读行，`complete=false`，
   `next_page` 给出应继续或重读的页号；部分结果不升级为空或完整。
6. **费用**：只接受非负整数分。展示值用整数除法生成（`123456 -> 1234.56`），不使用浮点，
   也不再次乘以 100。来源未给费用时 `fees.state=UNKNOWN`，不是 0 元。
7. **规则**：每条规则保留原字段、值、单位、来源和 `checked_at`。缺失字段是 `MISSING`，
   不是无限制；类型不符是 `TYPE_MISMATCH`；体育 `cancelTime`/`deadlineTime` 单位不唯一，
   保留 `UNIT_AMBIGUOUS` 和 `null`，不推算分钟或时刻。
8. **状态轴**：体育预约阶段、审批、付款、退款分别映射。任一轴缺失或为未知枚举时整体
   `status=UNKNOWN`、`state_confirmed=false`，同时保留未知轴的不可逆摘要；只有四个轴都可
   映射时才读取取消位。`PAID` 只是平台付款状态，`payment_receipt_verified=false`。
9. **公开脱敏**：其他人物业只保留开始/结束时间和平台状态；合成人员姓名、登录名、主题和
   电话不会进入公开预检或 JSON 输出。
10. **兼容**：旧操作名、参数、旧字段和旧状态字符串保持不变；新增字段均可选。写开关全部
    关闭时，`describe` 仍列出全部只读操作，`library`/`sports` 只读入口继续工作。
