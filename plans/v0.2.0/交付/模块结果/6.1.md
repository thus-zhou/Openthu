## 交付范围

- `src/thu_assistant/facade/`（新目录，`__init__.py`、`core.py`、`registry.py`、`requests.py`、
  `errors.py`）：冻结的 `business-facade-v1` 对象。`query`/`health` 只读，`prepare` 只写本地加密计划，
  `execute` 是唯一校园写入路径且要求可信宿主授权，`result` 只核对不重发，`cancel` 只取消本地请求。
  门面负责账号域、请求范围、统一信封和错误分类；站点细节仍由各适配器负责。
- `facade/registry.py`：能力登记表。登记项来自各模块自己的能力报告或组合根提供的提供者，
  每项带 `kind`、`owner`、`adapter_version`、`state`（`AVAILABLE`/`DISABLED`/`BLOCKED`/`MISSING`）、
  `reason`、授权等级、副作用、证据级别、`prepare_allowed`、`executable`。同一名称冲突时较严格的一项胜出。
  代码文件存在不构成可用证据；模块报告抛错会留下 `MISSING` 条目与一条脱敏的 `registration_failures` 记录。
- `facade/requests.py`：请求编号、队列/运行状态、取消事件、清理钩子的单一绑定。排队取消立即生效；
  运行中取消记为 `CANCELLATION_REQUESTED`，处理函数返回后仍保持 `CANCELLED`；业务失败记为 `FAILED`；
  已结束请求不会重放。清理副作用只执行一次。
- `facade/core.py`：`BusinessFacade`。`query` 只接受登记表内的只读操作，拒绝写操作名和
  `method`/`headers`/`token`/`cookie` 等代理字段（含嵌套），`url` 只允许用于已登记的 `campus.page`；
  未登记操作保留旧码 `UNREGISTERED_QUERY_OPERATION`，不再回退到 `QueryEngine`。`health` 只报告本地登记
  （`live_probe=false`），按 `OK`/`PARTIAL`/`BLOCKED`/`DISABLED`/`MISSING`/`UNKNOWN` 聚合；单个服务失败
  不影响其它服务。`prepare` 只对「来源契约未验证且不允许准备」和「写开关关闭」返回具体缺口，其余交给
  对应引擎保留原有 `ADAPTER_REQUIRED` 计划形状。`execute` 对 `BLOCKED` 写操作在 preflight 之前拒绝。
  `result` 按记录所属引擎只读核对。`export_agenda` 是显式的本地写，校验 `overwrite`/`allow_partial`
  类型与格式后把绝对路径规则交给 5.4。
- `src/thu_assistant/local_ops.py`：`local` 服务的三个本地汇总读取定义
  （`agenda`、`agenda_changes`、`resources`），版本号取自 5.4/4.2 模块常量，schema 与能力登记共用一张表。
  `resources` 只暴露 `semester`/`query`/`course_id`，分页用 `cursor`/`page_size`。
- `src/thu_assistant/queries.py`：只改注册部分。新增 `local` 伪服务的登记与分派；`describe` 允许
  `local` 且不再为它套用 `page`/`status` 通配；`agenda`/`agenda_changes` 用同一份快照分页，
  `change_cursor`（增量基线）与 `next_cursor`（本次变更集分页）分开；`resources` 按提供者的
  `max_search_limit`（4.2 默认 50）读取，超过上限时 `source_complete=false` 并给出
  `RESOURCE_SEARCH_LIMIT_APPLIED`，`verification_level=LOCAL_EXECUTION_STATE`，`checked_at` 缺失时回退到
  本次查询时间。原 29 个工具、原参数和原结果字段保持不变。
- `src/thu_assistant/mcp_stdio.py`：`CampusAssistant` 增加可选注入的 `resources`、`media`、
  `media_binding`、`submissions`、`facade`；`describe_service`/`query_service`/
  `prepare_service_action`/`execute_service_action`/`get_action_result` 改走门面；
  `model_chat` 把宿主提供的媒体绑定传给 4.5 的媒体管道（未提供时保持 `MODEL_IMAGE_INPUT_UNAVAILABLE`）；
  按 5.1 的跨模块请求登记 `('library','renew_loan') → RenewalAction`；错误结果从任意字符串 `.code`
  取码（不再要求 `CampusError` 子类）并补充 `category`/`retryable`/`automatic_replay_allowed`/`user_action`
  与被拒能力块；主循环改为 `RequestRunner`，JSON-RPC 编号按类型区分（`int:1`/`str:1`），
  `notifications/cancelled` 同时设置传输取消与门面状态，请求数超限时返回带分类字段的错误。
- `src/thu_assistant/__main__.py`：命令行改为子命令，保留 `services`/`discover`/`login`/`read`/
  `courses`/`model` 原有参数，新增 `describe`、`health`、`query`、`agenda`（可 `--export` 导出本地
  日历）、`dashboard`。`dashboard` 在 6.2 的 `thu_assistant.local_api` 提供者缺失时返回
  `LOCAL_DASHBOARD_UNAVAILABLE`，并已固定公共调用参数 `host`/`port`/`facade`。标准输出只有一个
  JSON 对象，错误从任意字符串 `.code` 取码并输出分类字段。
- `contracts/v0.2/error-classification.json`、`src/thu_assistant/source_state.py`：登记 13 个新错误码
  （7 个门面、5 个提供者缺口、1 个本地看板缺口），两侧完全一致。
- `contracts/v0.2/local-read-api.schema.json`：`/resources` 增加 `semester` 参数说明（4.2 索引按学期，

- `README.md`：补充 6.1 CLI 子命令、`command` 字段、分类错误对象和参数位置变化的迁移说明。
- `tests/test_facade.py`（37 例）、`tests/test_cli.py`（8 例）、`tests/test_facade_audit.py`（23 例）：
  共 68 个模块用例，其中审计回归按 P1-1…P2-15 命名。

## 限制

- `thu_assistant.local_api`（6.2）尚未提供，`openthu dashboard` 目前只返回
  `LOCAL_DASHBOARD_UNAVAILABLE`；公共参数 `host`/`port`/`facade` 已在 CLI 固定，回接时无需改动门面。
- 4.2 资料中心需要一个注入的索引存储；6.1 不自行创建生产索引，因此 `local.resources` 默认是
  `RESOURCE_PROVIDER_UNAVAILABLE`。注入 `ResourceCenter` 后即可用，并受该提供者
  `max_search_limit`（默认 50）限制，超出时标记为不完整。
- `local.resources_export` 与 `local.media_prepare` 是 `MISSING`/`NO_PUBLIC_ENTRY`：4.2 的
  `export_summary` 与 3.3 的 `register_user_file` 只在宿主 API 可用，6.1 不提供 CLI/MCP 入口。
- 3.3/4.5 媒体管道需要组合根注入 `MediaAssets` 与 `MediaBinding`；未注入时图片调用保持
  `MODEL_IMAGE_INPUT_UNAVAILABLE`，4.5 的协议注册表仍为空，目录标注不会开启传输。
- 续借 `renew_loan` 只能准备官方移交计划和读取结果；`execute` 在执行前被门面以
  `SOURCE_CONTRACT_UNVERIFIED` 拒绝，`THU_LIBRARY_RENEW=0` 时整个能力为 `DISABLED`。
- 作业提交、个人课表/考试/成绩仍为来源阻塞；本模块只登记能力缺口，不伪造空成功。
- `health` 是静态能力登记，不代表已登录、来源可读或业务可用；每次 `query` 仍会真实读取来源。
- `agenda`/`agenda_changes`/`resources` 的游标是进程内快照，十分钟有效；`change_cursor` 与
  `next_cursor` 语义不同，不能互换。
- `contracts/v0.2/local-read-api.schema.json` 的 `semester` 是兼容追加修订，6.2 需提供用户选择或
  配置的当前学期。
- 批次 6 仍未完成：6.2 与 6.3 pending，本模块 accepted 不等于批次通过。
