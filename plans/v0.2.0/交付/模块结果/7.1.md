## 交付范围

- `src/thu_assistant/web_assets/index.html`：六个页面的空壳、跳过链接、只读说明、会话横幅、
  `aria-live` 状态区和 `noscript` 提示。所有脚本/样式只用相对 `assets/` 路径，且带
  `crossorigin="anonymous"`，使浏览器以 CORS 模式请求同源静态子资源（见边界）。
- `src/thu_assistant/web_assets/assets/model.js`：纯展示模型，无 DOM、无网络。负责：
  - `display.state` 到中文标签/色调的映射（`READY`、`EMPTY`、`PARTIAL`、`LOGIN_REQUIRED`、
    `LOCAL_SESSION_REQUIRED`、`LIMITED`、`FORBIDDEN`、`MAINTENANCE`、`ERROR`、`UNKNOWN`），
    另有本地 `NEEDS_INPUT`、`NOT_ENABLED` 两种不同文案；
  - 来源时间（Asia/Shanghai，日期级单独标注）、实时性（实时/快照/历史缓存/本地状态/未标注）、
    完整性（来源、快照、范围、缺页、更多页）和下一步；
  - 课程/资料过滤、资料类型推导、稳定编号选择、筛选参数变更后的快照失效、分页参数构造；
  - `calendar-event-v1` 的嵌套 `time` 与冻结样例的扁平 `start/end` 两种形态统一成
    日期级/精确时间；逾期、冲突、缺少校历/节次表的限制说明；
  - 链接白名单：只允许 `https://*.tsinghua.edu.cn`（不含 CAS/SSO/login/ticket 参数）；
  - 文本清理：移除 C0 控制符、双向控制符和零宽字符，按长度截断。
- `src/thu_assistant/web_assets/assets/api.js`：唯一网络出口。只接受 `/api/v1/...` 相对路径，
  只发送 `GET`，`credentials: 'same-origin'`、`redirect: 'error'`、`referrerPolicy: 'no-referrer'`，
  35 秒本地超时；不保存 Cookie/令牌，不接受请求方法参数。
- `src/thu_assistant/web_assets/assets/app.js`：DOM 渲染与页面状态：
  - 总览七张卡片（来源健康、待办、课程、资料、借阅、图书馆预约、体育预约），每张独立读取；
    一张失败或取消不影响其他卡片；
  - 课程页：学期、类型（学生/教师/助教/其他）、关键词过滤；课程行可跳到资料页并带课程编号，
    同时清空上一页的关键词和类型筛选；
  - 资料页：学期、课程编号、类型、关键词过滤；跨页选择按 `stable_resource_uid` 保留，
    普通重进不丢选择和已加载页；筛选参数变化时递增读取代号、终止旧请求并清除选择、游标和旧快照；

    首版不执行下载或导出，提示使用原有受控工具；
  - 日程页：时间线/列表切换不重新请求；逾期、今天、即将、无日期、已完成分区；

## 边界与保留限制

- **P1-1 已闭环**：`src/thu_assistant/__main__.py` 导入 `web_assets`，`--check` 与 serve 两处
  `LocalApiServer(...)` 都传 `static_dir=web_assets.static_dir()`；真实 CLI 服务 `GET /` 返回 200，
  `GET /assets/app.css` 返回 200。该接线属于 6.1 公共入口，本模块按 owner 要求代改，集成人应复核
  这处小差异。
- **P1-2 已闭环**：`pyproject.toml` 的 package-data 增加 `web_assets/*.html`、
  `web_assets/assets/*.css`、`web_assets/assets/*.js`；`MANIFEST.in` 递归收同目录。wheel/sdist
  用例已断言 `index.html`、`app.css`、`app.js` 都在产物中；该元数据属于 6.3，集成人应复核打包模式。
- **静态子资源模式**：6.2 的 `fetch_metadata_allowed` 只允许 `Sec-Fetch-Mode` 为
  `navigate/cors/same-origin`；Chromium 对 `<script crossorigin>`/`<link crossorigin>` 发
  `cors`，因此本模块可用。若 7.2 在 Firefox/Safari 上观察到同源静态资源仍发 `no-cors`，
  需要 6.2 在静态路由接受同源 `no-cors`（不得放宽跨站）。本模块不改本地 API。
- `/resources` 必须带学期；看板不猜默认学期。学期清单读取失败时提供手填学期编号的输入，
  未选择学期时只显示“需要先选择学期”，不返回空成功。资料类型过滤只在已加载页上生效，
  因为冻结的 `/resources` 查询没有 `kind` 参数；空结果明确写“当前已加载范围”并保留
  “加载更多”，不把第一页当成全部。服务端类型过滤仍属 4.2/8.1 契约工作。
- 日程分区由已加载的 `items` 计算，`conflicts` 使用 API 返回的冲突；`views` 不用于替代
  当前页数据。存在 `next_cursor` 时显示“还有更多页”的限制说明，不把第一页当成完整日程。
- 资料选择只影响页面内的导出范围说明，不执行下载、导出或写入；正式导出仍走 4.2/6.1 的受控路径。
- 成绩、原始敏感详情、密钥和写操作不在看板提供；需要时使用原有受控工具，并保持最小字段投影。
- 10 秒复用是页面内存缓存，镜像 `refresh_min_seconds`；页面关闭、会话失效或服务不可达即清空。
  没有跨进程、跨账号或跨浏览器持久化。
- 浏览器测试在缺少 Playwright/Chromium 的环境按平台原因跳过；其余静态与模型测试仍执行。
- 看板显示本地请求编号用于支持排查，不含账号、Cookie、令牌或用户目录。
