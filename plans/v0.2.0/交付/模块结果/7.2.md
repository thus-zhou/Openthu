## 边界与保留限制

- 7.1 是同一批次尚未回接的模块：矩阵把 `tests/test_web_assets.py` 标为 `pending_same_batch`，
  本工作区没有该文件；7.2 验证的是 6.2 的本地读取 API 协议和进程边界，不是 7.1 的看板界面。
  7.1 回接后必须把矩阵状态改为 `covered` 并补上真实看板用例。
- 7.3 是文档模块，8.1/9.1 是后续串行关口；矩阵分别标为 `documentation_only` 和 `future_gate`，
  没有为它们伪造测试。
- 本机为 Linux：Windows DPAPI、Windows ACL、Windows 会话迁移等用例以明确平台原因跳过。
  真实 Windows 结果必须由 CI 的 `windows-2025` 作业在同一提交产生；本记录不把跳过当通过，
  也不把 Windows 形状报告当 Windows 实跑证据。
- 跳过分类是策略性的：平台/环境提示词之外的新跳过原因会让门禁失败并要求解释；这是有意行为，
  不是遗漏。
- 精确标记扫描只覆盖安装产品 wheel。源码包和 sdist 按设计包含测试与 `marker_set.json`，
  由 `privacy_scan.py` 的通用凭据/敏感文件名规则覆盖；否则已提交的合成标记定义会自我误报。
- 故障注入使用 5.3 的合成提交传输和 2.2 的临时密钥；没有生产上传端点、真实账号或真实业务写入。
- 本地读取 API 超时用例使用 0.15 秒截止和不协作门面；工作线程可能持续到进程退出，这是 6.2
  已记录的进程边界，不是本模块新增的取消能力。
- 报告只保留错误类别和仓库相对节点编号；原始失败材料留在受控环境。跳过原因也经过路径/令牌
  脱敏，但报告仍是工程摘要，不是通用的数据防泄漏系统。
- 报告门禁在本地用真实 Linux JUnit 和同提交的 Windows 形状报告验证聚合；两平台 CI 的真实结果
  仍需 8.1 在集成提交上观察并记录。
- 候选包是本机候选构建，不是正式发行；没有合并 main、创建标签或上传 Release。
- `regression_report.py` 不新增运行依赖；CI 使用仓库已固定的 Python/Node 与显式 Chromium 安装。
