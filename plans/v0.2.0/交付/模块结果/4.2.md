## 实施要点

1. **来源集合**：课程文件、公告附件、作业附件分别映射到稳定标识；保留课程、学期、
   标题、源记录编号与关联正文读取状态。公告/作业附件列表必须显式
   `include_notice_details` / `include_assignment_details`，只调用既有读取方法。
2. **检索**：跨课程元数据与已读取的公告正文/作业说明；支持学期、课程、类型、更新时间、
   关键词组合与分页；返回 `matched_fields`、`body_coverage`、`total_known`、
   `checked_at`、`next_offset`。未读取的正文不会被说成已覆盖。
3. **加密索引**：只走 2.2 的 `SecureStore`（用途 `INDEX`，账号域 `CAMPUS`，服务域
   `LEARN`）；按账号与学期分记录；内存解密检索；默认 4 MiB、每学期 2000 条、
   保留期 180 天；不建立明文全文数据库。
4. **稳定清单**：逻辑键为 `(stable_resource_uid, version)`；同名不同编号保持两条；
   同编号不同版本保留历史；内容哈希相同但来源不同只做分组，不合并、不复用对方文件。
   来源更新时间只有日期或缺失时为 `UNKNOWN`，索引分配 `u<n>` 序列并标记。
5. **批量下载**：预览文件数、已知/未知大小、目标目录、相对路径、覆盖处理与冲突；
   执行必须 `confirm=True`；逐项记录成功、复用、冲突、失败、取消；单项失败不把整批
   写成完成，已成功项保留；相同内容不重复下载。
6. **归档**：安全课程目录 + 安全标题 + `(uid, version)` 短令牌；拒绝 `..`、绝对路径、
   Windows 保留设备名与超长名；临时文件写入后复核哈希再原子替换；已存在文件永不覆盖，
   哈希不同报告冲突；磁盘不足/文件占用保留原文件。
7. **导出**：默认字段为标识、来源、课程、学期、标题、版本、大小、更新时间、状态、
   检查时间与来源链接；包含正文摘录需要 `acknowledge_personal=True`；拒绝写入 Git
   工作树；导出是用户本地 JSON 摘要，不自动加入仓库或上传模型。
8. **生命周期**：索引刷新保留原始检查时间与来源错误；失败刷新把未再读到的条目标为
   `STALE`，默认不可下载，需 `allow_historical=True`；完整刷新可把缺失条目标为
   `MISSING`；`delete_cache` 用空索引原子替换旧密文；下载记录可查询；公开标识不含
   真实文件路径。

## 安全与隐私属性

- 标识来自源记录，不来自标题；`learn:FILE` 形状与
  `contracts/v0.2/samples/stability.json` 一致。
- 索引、下载记录与错误不含绝对下载目录；记录只有 `destination_id` 哈希与相对归档路径。
- 归档临时文件 POSIX 0600，写入后复核长度与 SHA-256；既有文件从不覆盖。
- 来源错误与警告先清洗为稳定代码再入索引，自由文本（路径、凭据样式）被丢弃。
- 包内不导入 socket/urllib/requests/http；不打印；测试用 socket guard 验证全流程无连接。
- 测试使用真实 AES-GCM `SecureStore`（file-key/DPAPI），没有关闭加密的测试模式。

## 已知边界

- 不解析 PDF、图片、Office 文档或录音；全文检索只覆盖已读取的公告正文与作业说明，
  `body_coverage` 会说明不完整。
- 公告没有附件时不形成资源条目，其正文不能单独检索。
- 默认复用已保存文件时不重新传输；同版本内容变化需要 `verify_known=True` 或来源给出
  新版本才会发现。
- 索引是进程内解密后的有界文档，不是增量全文搜索引擎；单账号单学期假定单写者，
  并发写者由 2.2 存储锁保护但仍以最后写入为准。
- 计划只在当前进程有效（默认 10 分钟、一次性）；重启后需要重新预览。
- `STALE` 条目默认不可下载，必须显式 `allow_historical=True`；`MISSING` 需要
  `include_superseded=True` 才能查看。
- 归档写入假定同一目录单写者；并发写者只会遇到冲突，不会覆盖。
- 本模块未接入 `queries.py`/MCP/CLI；真实门面与错误码登记由 6.1 完成。
- 本模块结果不代表真实校园读取或下载证据；所有验收均为合成账号、合成文件与假传输。
