## 2. 开发环境

项目使用仓库内 `.venv`：

```sh
source .local/activate.sh
unset PYTHONPATH
```

`unset PYTHONPATH` 是本次核对发现的必要步骤：当前云端 shell 继承了一个外部 Python 3.14 site-packages 路径，会遮蔽项目 `.venv` 中的包，使 `requests` 显示为 2.34.2。清理后项目环境恢复为锁定的 2.33.0。该外部路径不写入仓库，也不属于项目依赖。
