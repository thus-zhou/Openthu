## 五、已知限制与保留边界

- 来源阻塞（非缺陷）：续借请求契约、作业提交端点、学业四项来源、模型图片协议均为 `BLOCKED_SOURCE_EVIDENCE`；候选不把它们写成可用。
- 真实校园认证依赖 Windows DPAPI；Linux 只有本地加密存储，没有生产级校园登录。
- 本地看板只读，Chromium 已实测；Firefox/Safari 的静态子资源 `Sec-Fetch-Mode` 未验证。
- 本地 API 的 HEAD 执行一次读取但不占 10 秒刷新配额；bootstrap 令牌一次性，会话过期需重启实例。
- 旧 `learn_assistant.core.prepare_submission` 仍写本地未加密预览 JSON（含本地路径、不上传、不提交），属 v0.1 兼容路径的本机状态边界。
- wheel 不含 `node_modules`；需要网关能力的用户按 `docs/INSTALL.md` 在包目录执行 `npm ci --ignore-scripts`。
- 未安装 Node 依赖时网关能力返回分类错误；这是资源未就绪，不是来源或业务结论。
